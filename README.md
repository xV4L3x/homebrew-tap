# XV4L3x Tap

## How do I install these formulae?

`brew install xv4l3x/tap/<formula>`

Or `brew tap xv4l3x/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "xv4l3x/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
